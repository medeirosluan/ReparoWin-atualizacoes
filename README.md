# ReparoWin - atualizações

Este repositório guarda apenas o arquivo `versao.json`, que o botão **Verificar atualizações** do ReparoWin lê para saber se existe uma versão nova.

Não contém o código do programa nem o instalador.

Formato do arquivo:

```json
{
  "versao": "1.15",
  "url": "https://endereco-da-pagina-de-download",
  "notas": ["o que mudou"]
}
```
